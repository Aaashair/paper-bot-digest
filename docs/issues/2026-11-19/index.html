Evolve in Panorama, Render in View: Panoramic World State Evolution for Video World Models
全景隐空间持续演化世界，再按视角渲染透视视频
为什么值得看针对未观测区域被冻结，提出在全景视频隐空间演化世界状态、再用透视扩散模型读取渲染的新分解，并构建真实360°事件数据；在WRBench（23个公开模型）与STEVO-Bench取得最优，开辟了全景状态作为视频世界模型的小方向。
作者Longtao Jiang, Mingfei Han, Jianmin Bao 等 10 人
机构MBZUAI / Kuaishou
评测WRBench、STEVO-Bench

OpenAI · 大厂官方

GPT-Live-1.1

OpenAI 于 11 月 19 日把全双工语音模型 GPT-Live-1.1 开放到 Live API（v1/live/sessions），并新增 WebRTC Standby 空闲计费。

这是 ChatGPT Voice 同款全双工前端首次对开发者开放：边听边说、更好的多语口音/转写，以及把推理与工具交给后端模型而不打断对话。

Google DeepMind / Google Labs · 大厂官方

Genie 4 is now available

DeepMind 向 Google AI Ultra 的 Project Genie 开放 Genie 4：实时交互世界首次配对原生音频（环境声、音效与角色对话）。

世界模型从无声画面变成可导航的音视频场景，是音频生成进入实时仿真的一次产品级落地；次日 Gemini API 也可调用。

Hugging Face / Reson8 · 大厂官方

Rumble-2-Flash: an open 0.5B speech model for 40+ languages

Hugging Face 官方博客开源 Apache-2.0 的 0.5B 多语 ASR 模型 Rumble-2-Flash，原生支持 Transformers/vLLM，覆盖 40+ 语言。

用 on-policy 蒸馏把大模型压到 0.5B，多语 Open ASR 平均错误率约 6.96%，电话场景接近 30B 级 Nemotron Transcribe，是小模型语音识别的新参考点。

Cartesia · 大厂官方

ink-preview (44-language streaming STT)

Cartesia 在官方 STT 文档中发布 ink-preview：44 语流式识别，带语言检测、词级时间戳，以及最多 500 条可中途热更新的 keyterm。

这是面向语音 Agent 的新一代流式 ASR 预览，补上 ink-2 没有的语种覆盖、code-switching 检测和通话中途改词表。
