## 规则

- 摘要初评组建精审池 → 全文 10 分制审稿（新意 0–3、影响力 0–3、实证 0–2、契合度 0–2）→ Area Chair 校准 → Senior AC 复核 A。
- 板块 1–5：≥7 分进 B；A 需 ≥8、新意或影响力 3、实证 2。板块 6–7 只收 A。实证 0 或契合 0 直接淘汰。不设篇数上限。
- 数字、机构、链接只用全文核实过的；「研究联想」是模型推测。
